# 💣 Bomb Clicker

Невелика аркадна гра на Python (tkinter) у мінімалістичному стилі Apple.
Гніт бомби постійно горить, а ти клікаєш по ній, щоб він не догорів. Що довше протримаєшся, то більший рахунок.

## Запуск

Потрібні **Python 3.8+** і бібліотека **Pillow**.

```bash
pip install pillow
python main.py
```

Окремі файли з картинками не потрібні: гра сама малює всю графіку.

## Як грати

1. Натисни **«Почати гру»**, `Enter` або `Space`.
2. Клікай по бомбі (або по кнопці «Клік!», або тисни `Space`). Кожен клік додає гноту.
3. Гніт горить дедалі швидше. Коли він закінчиться, бомба вибухне.
4. Рахунок дорівнює кількості секунд, які ти протримався. Найкращий результат зберігається між запусками.

### Керування

| Клавіша / дія          | Що робить                     |
|------------------------|-------------------------------|
| Клік по бомбі          | +2% гноту                     |
| `Space`                | клік, або старт, якщо гра не йде |
| `Enter`                | почати / грати ще             |
| `D`                    | перемкнути світлу/темну тему  |

Затиснутий `Space` не дає автоклік: щоб клікнути ще раз, клавішу треба відпустити.

## Особливості

- **Дизайн у стилі Apple:** системна палітра кольорів, картки з м'якими тінями, кнопка-«пілюля», шрифт Segoe UI Variable (або SF Pro, якщо він встановлений).
- **Кільце гноту** як на Apple Watch: плавно зменшується й міняє колір із зеленого на помаранчевий, а потім на червоний.
- **Анімації:** бомба «пружинить» при кліку, над нею спливає «+2», іскра мерехтить, а коли гноту мало, бомба тремтить. Вибух супроводжують розліт частинок і тремтіння екрана.
- **Світла й темна теми.** Тема вибирається автоматично за налаштуваннями Windows. На Windows 11 заголовок вікна фарбується в колір фону.
- **HiDPI:** інтерфейс масштабується під екрани зі збільшенням 125%, 150% тощо.
- **Рекорд** зберігається у файлі `best_score.txt` поруч із грою.

## Налаштування балансу

Параметри гри задаються константами на початку [`main.py`](main.py):

| Константа      | За замовчуванням | Опис                                   |
|----------------|------------------|----------------------------------------|
| `START_FUSE`   | `100.0`          | початковий (і максимальний) гніт, %    |
| `CLICK_BONUS`  | `2.0`            | скільки гноту додає один клік          |
| `BASE_BURN`    | `10.0`           | швидкість горіння на старті, % / с     |
| `BURN_RAMP`    | `0.2`            | наскільки горіння прискорюється щосекунди |
| `MAX_BURN`     | `22.0`           | максимальна швидкість горіння, % / с   |
